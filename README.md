# LesPetitsPlats – Accessible recipe search application (JavaScript)

## Project context
This project was developed as part of the **Application Designer & Developer (React-oriented)** training program by OpenClassrooms.  
It is the fifth JavaScript front-end project in the curriculum and focuses on building an accessible and dynamic recipe search interface using pure JavaScript, consuming a local API.

The goal was to build a user-friendly recipe browsing experience with search, filters, and accessibility compliance.

## Educational objectives
- Build a dynamic front-end application in JavaScript (ES6+)
- Consume and filter data from a local API
- Manipulate the DOM to display updated content
- Implement search and multi-criteria filtering
- Apply accessibility best practices (WCAG, ARIA)
- Structure JavaScript code modularly

## Technologies used
- JavaScript (ES6+)
- HTML5
- CSS3
- DOM manipulation
- Accessibility features (ARIA, keyboard navigation)
- Git / GitHub
- GitHub Pages (deployment)

## Features
- Search recipes in real time
- Filter recipes by multiple criteria (ingredients, appliances, utensils)
- Display recipe cards dynamically
- Accessible interface with keyboard support
- Responsive layout for various screen sizes
